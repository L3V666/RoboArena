# Алгоритмы RoboArena

## A* pathfinding

Карта рассматривается как граф:

- клетка — вершина;
- переход в соседнюю проходимую клетку — ребро;
- стены не входят в список соседей.

A* выбирает следующую клетку по сумме:

```text
priority = cost_from_start + heuristic_to_goal
```

В проекте используется манхэттенская эвристика, потому что движение идёт по четырём направлениям: вверх, вниз, влево, вправо.

## Используемые контейнеры

- `std::priority_queue` — очередь открытых вершин;
- `std::unordered_map` — стоимость пути до клетки;
- `std::unordered_map` — восстановление маршрута через `cameFrom`;
- `std::vector` — итоговый путь.

## Удаление объектов

Сущности не удаляются сразу из середины цикла обновления. Вместо этого объект помечается как уничтоженный, а потом `EntityManager` удаляет такие объекты через erase-remove idiom.

Это безопаснее, потому что не ломает обход контейнера во время игровой логики.

## Сложность

Для сетки из `V` проходимых клеток и `E` переходов A* работает примерно за:

```text
O((V + E) log V)
```

Логарифм появляется из-за `std::priority_queue`.
