# Этапы разработки RoboArena

## Stage 1 — базовый каркас

- CMake-проект.
- Разбиение на `include/` и `src/`.
- Окно SFML.
- Игровой цикл.
- Клеточная карта.
- Игрок с движением и коллизиями.

## Stage 2 — сущности и враги

- Базовый класс `Entity`.
- `EntityManager`.
- Хранение сущностей через `std::vector<std::unique_ptr<Entity>>`.
- Базовый класс `Enemy`.
- Конкретный враг `ChaserEnemy`.

## Stage 3 — поиск пути

- Система `Pathfinder`.
- A* по клеточной карте.
- Использование `std::priority_queue` и `std::unordered_map`.
- Враги обходят препятствия через маршрут по графу.

## Stage 4 — боевая система

- Снаряды игрока.
- `CombatSystem`.
- Урон врагам.
- Контактный урон игроку.
- Удаление уничтоженных сущностей.
- Счёт игрока.

## Stage 5 — волны и прогрессия

- `WaveSystem`.
- Несколько волн врагов.
- Спавн по таймеру.
- Победа после прохождения всех волн.
- Перезапуск игры.
- HUD с HP, прогрессом волны и перезарядкой.

## Stage 6/7 — бонусы и финальная полировка

- `PowerUp`.
- `PickupSystem`.
- Аптечка, ускорение и скорострельность.
- Таймеры временных эффектов.
- Главное меню.
- Выбор сложности.
- Пауза.
- Экраны победы и поражения.
- Дополнительная документация по архитектуре и алгоритмам.
