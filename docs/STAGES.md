# Этапы разработки RoboArena

## Этап 1

Создан базовый каркас проекта:

- CMake-проект;
- структура `include/` и `src/`;
- окно SFML;
- игровой цикл;
- карта;
- игрок;
- движение и базовые столкновения.

## Этап 2

Добавлена система сущностей:

- базовый класс `Entity`;
- `EntityManager`;
- хранение сущностей через `std::vector<std::unique_ptr<Entity>>`;
- базовый класс `Enemy`;
- первый враг `ChaserEnemy`.

## Этап 3

Добавлен поиск пути:

- `Pathfinder`;
- A* по клеточной карте;
- `std::priority_queue`;
- `std::unordered_map`;
- движение врагов по маршруту.

## Этап 4

Добавлена боевая система:

- снаряды `Projectile`;
- стрельба мышью;
- здоровье игрока;
- здоровье врагов;
- `CombatSystem`;
- урон от снарядов;
- контактный урон врагов;
- удаление уничтоженных объектов.

## Этап 5

Добавлены волны врагов и игровой прогресс:

- `WaveSystem`;
- последовательные волны противников;
- спавн врагов по таймеру;
- победа после прохождения всех волн;
- перезапуск игры клавишей `R`;
- HUD с полосой здоровья, прогрессом волны и индикатором перезарядки.
