# Архитектура RoboArena

## Общая схема

Проект разделён на несколько независимых слоёв:

```text
core      — главный игровой цикл и состояния игры
entities  — игровые объекты
systems   — независимые системы обработки логики
map       — клеточная карта
math      — вспомогательные векторные функции
```

## `Game`

`Game` управляет главным циклом:

1. обработка событий;
2. обновление состояния;
3. отрисовка.

Также в `Game` хранится текущее состояние игры:

```cpp
enum class GameState {
    MainMenu,
    Playing,
    Paused,
    Victory,
    GameOver
};
```

Это позволяет не обновлять волны, врагов, бонусы и бой во время меню, паузы или финального экрана.

## `Entity`

`Entity` — общий интерфейс для игровых объектов:

```cpp
virtual void update(float deltaTime) = 0;
virtual void draw(sf::RenderWindow& window) const = 0;
virtual sf::FloatRect getBounds() const = 0;
```

Наследование используется для объектов с общим жизненным циклом, но разным поведением: игрок, враги, снаряды и бонусы.

## `EntityManager`

`EntityManager` владеет сущностями через `std::unique_ptr<Entity>`.

Преимущества:

- автоматическое освобождение памяти;
- единое место владения объектами;
- полиморфная обработка через базовый класс;
- шаблонное создание объектов через `create<T>()`.

## Системы

Системы отделяют игровую механику от конкретных сущностей:

- `Pathfinder` ищет путь;
- `CombatSystem` обрабатывает попадания и контактный урон;
- `WaveSystem` управляет волнами и сложностью;
- `PickupSystem` создаёт бонусы и применяет эффекты.

Такой подход делает код проще расширять: можно добавить новый тип врага или бонуса, не переписывая главный игровой цикл.
