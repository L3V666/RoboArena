# RoboArena

**RoboArena** — 2D-игра на C++17 и SFML. Игрок управляет роботом на арене, стреляет по врагам, переживает несколько волн противников, собирает временные бонусы и выбирает сложность перед стартом. Враги строят путь до игрока по клеточной карте с помощью A*.

## Возможности текущей версии

- окно SFML и игровой цикл;
- главное меню;
- выбор сложности: `Easy`, `Normal`, `Hard`;
- пауза во время игры;
- экран победы и поражения;
- карта-арена на сетке;
- движение игрока с коллизиями;
- базовая система сущностей `Entity`;
- хранение сущностей через `std::vector<std::unique_ptr<Entity>>`;
- шаблонное создание сущностей через `EntityManager::create<T>()`;
- шаблонный поиск сущностей через `EntityManager::getAll<T>()`;
- базовый класс `Enemy` и наследник `ChaserEnemy`;
- A* pathfinding для врагов;
- снаряды игрока;
- отдельная `CombatSystem`;
- здоровье игрока и врагов;
- удаление уничтоженных сущностей;
- волны врагов через `WaveSystem`;
- бонусы на карте через `PickupSystem`;
- аптечка, ускорение и скорострельность;
- временные эффекты игрока с таймерами;
- HUD с полосой здоровья, прогрессом волны, перезарядкой, бонусами и таймером следующего бонуса.

## Управление

```text
Enter — начать игру из главного меню
Tab — сменить сложность в главном меню
WASD / стрелки — движение
ЛКМ — выстрел
P — пауза / продолжить
R — перезапуск
Esc — пауза во время игры, выход из меню или финального экрана
```

## Сборка

Требования:

- C++17;
- CMake 3.16+;
- SFML 2.5+.

```bash
mkdir build
cd build
cmake ..
cmake --build .
./RoboArena
```

## Основные модули

### `core`

Содержит класс `Game`, который управляет главным циклом, событиями, состояниями игры, обновлением и отрисовкой.

Игровые состояния:

- `MainMenu`;
- `Playing`;
- `Paused`;
- `Victory`;
- `GameOver`.

### `entities`

Содержит игровые сущности:

- `Entity`;
- `Player`;
- `Enemy`;
- `ChaserEnemy`;
- `Projectile`;
- `PowerUp`.

Наследование используется осмысленно: у игровых объектов есть общий интерфейс `update()`, `draw()`, `getBounds()`, но поведение разное.

### `systems`

Содержит независимые системы:

- `EntityManager`;
- `Pathfinder`;
- `CombatSystem`;
- `WaveSystem`;
- `PickupSystem`.

`WaveSystem` отвечает за порядок волн, интервалы спавна, сложность и проверку победы. `PickupSystem` отвечает за появление бонусов, проверку подбора и применение эффектов к игроку.

### `map`

Содержит клеточную карту `GridMap`. Карта хранится как вложенный контейнер:

```cpp
std::vector<std::vector<Tile>> tiles_;
```

## Алгоритмы

Враги используют A* для поиска пути по карте. Клетки карты рассматриваются как вершины графа, а переходы между соседними проходимыми клетками — как рёбра.

В реализации используются:

- `std::priority_queue` для frontier;
- `std::unordered_map` для стоимости пути и восстановления маршрута;
- `std::vector` для хранения итогового пути.

## STL и оптимизация

В проекте используются:

- `std::vector`;
- `std::vector<std::vector<Tile>>`;
- `std::unique_ptr`;
- `std::make_unique`;
- `std::move`;
- `std::priority_queue`;
- `std::unordered_map`;
- `std::remove_if`;
- `std::array`;
- range-based `for`.

`std::vector` выбран для хранения сущностей и карты из-за хорошей кэш-локальности. Удаление уничтоженных объектов выполняется через erase-remove idiom.
